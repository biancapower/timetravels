# 0013. The tagline: plain words, not one sentence

**Context.** The README, the installed app's description, the page's meta description and `package.json` all described TimeTravels as "a time calculator you talk to in one sentence". While writing the About page, the maintainer pointed out that the emphasis is wrong: what matters is that the question reads as plain language, the way you would say it, not that it is a single sentence.

**Decision.** The tagline is "A time calculator you ask in plain words, the way you'd ask a person." It replaces the old line in the README, the web app manifest, the page's meta description and `package.json`. The About page opens with the same idea, and Help describes the question as "an everyday sentence, the way you'd say it out loud".

**Alternatives.** "TimeTravels answers time questions asked the way you'd say them out loud." "A time calculator you ask in plain language, the way you'd say it out loud." Keeping "in one sentence".

**Reasons.** It names what makes the app different from a form or a converter: you ask it the way you would ask a person. "One sentence" describes the layout, not the experience.

**Consequences.** Anyone who installed the app sees the new description after the next update. The README's opening claim changes, which is why this is recorded.

**Status.** Proposed by @biancapower (the emphasis) and Claude (the wording); approved by @biancapower, 2026-10-11.
